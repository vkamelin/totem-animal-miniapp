Для миниаппа «Тотемное животное» лучше не делать мистический фиолетово-чёрный стиль. По спецификации это развлекательный тест с лёгкой игровой типологией, без псевдонаучного и мистического пафоса, с живым и немного ироничным тоном результата . Поэтому цветовая схема должна быть тёплой, природной, игровой, но не детской.

Основная схема:

```css
:root {
  --color-bg: #F6F1E7;
  --color-surface: #FFF9EE;
  --color-surface-muted: #E9DDC8;

  --color-primary: #D96B32;
  --color-primary-hover: #C45D2B;
  --color-primary-soft: #F2B279;

  --color-secondary: #2F6F5E;
  --color-secondary-hover: #285F51;
  --color-secondary-soft: #BFD8C8;

  --color-accent: #F2C94C;
  --color-accent-soft: #F8E6A0;

  --color-text: #2B241C;
  --color-text-muted: #7A6D5E;
  --color-text-inverse: #FFF9EE;

  --color-border: #D8C8B2;
  --color-error: #B94A3A;
  --color-success: #4F8A5B;
}
```

Логика цветов:

`#F6F1E7` — основной фон. Тёплый песочный, даёт ощущение природности и не выглядит как медицинский тест.

`#FFF9EE` — карточки вопросов, результатов, блоков с животными. Светлее фона, но без стерильного белого.

`#D96B32` — основной CTA: начать тест, следующий вопрос, показать результат. Это терракотово-рыжий цвет, хорошо связан с темой животных, земли, шерсти, леса, но не уходит в эзотерику.

`#2F6F5E` — вторичный цвет: прогресс, декоративные элементы, заголовки секций, спокойные кнопки. Даёт природный баланс к тёплой палитре.

`#F2C94C` — акцент для бейджей, процентов совпадения, небольших игровых деталей. Использовать дозированно, иначе интерфейс станет слишком жёлтым.

`#2B241C` — основной текст. Мягче чистого чёрного и лучше сочетается с тёплым фоном.

Пример Tailwind-конфига:

```ts
export default {
  theme: {
    extend: {
      colors: {
        app: {
          bg: '#F6F1E7',
          surface: '#FFF9EE',
          surfaceMuted: '#E9DDC8',

          primary: '#D96B32',
          primaryHover: '#C45D2B',
          primarySoft: '#F2B279',

          secondary: '#2F6F5E',
          secondaryHover: '#285F51',
          secondarySoft: '#BFD8C8',

          accent: '#F2C94C',
          accentSoft: '#F8E6A0',

          text: '#2B241C',
          muted: '#7A6D5E',
          inverse: '#FFF9EE',

          border: '#D8C8B2',
          error: '#B94A3A',
          success: '#4F8A5B',
        },
      },
    },
  },
}
```

Практическое распределение:

```text
Фон приложения:        app.bg
Карточки:             app.surface
Основные кнопки:      app.primary
Вторичные кнопки:     app.secondary
Прогресс теста:       app.secondary
Выбранный ответ:      app.primarySoft + border app.primary
Обычный ответ:        app.surface + border app.border
Заголовки:            app.text
Подписи:              app.muted
Бейдж результата:     app.accent
Ошибки:               app.error
Успешные состояния:   app.success
```

Эта схема подходит под VK Mini App: она достаточно контрастная, хорошо ложится на карточный мобильный интерфейс, не выглядит тяжёлой и поддерживает тему животных без визуального пафоса.
